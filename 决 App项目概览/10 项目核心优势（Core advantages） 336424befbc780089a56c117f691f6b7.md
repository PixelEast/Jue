# 10. 项目核心优势（Core advantages）

---

| **优势** | **说明** |
| --- | --- |
| **隐私优先** | 核心决策数据 100% 本地存储，不上传云端 |
| **自主可控** | 自建登录和支付验证系统，不依赖第三方服务 |
| **国内合规** | 使用国内云服务，符合 PIPL 等法规要求 |
| **跨平台支持** | iOS + Android 双端，订阅状态可跨设备恢复 |
| **低运营成本** | 服务器及运营月成本低，可持续运营 |
